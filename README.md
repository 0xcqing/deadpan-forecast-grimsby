A tiny Node.js 22 program that writes one deadpan weather forecast for a city that does not exist. It emits a single line of at most 160 characters to `/output/entry.txt`.

> Grimsby-on-Ash, pop. 412: dew point projected to exceed local body temp by morning; forecast 100% humidity or sudden personal raincoat commerce.

## Run it

```sh
node main.ts
```

Output is written to `$MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
